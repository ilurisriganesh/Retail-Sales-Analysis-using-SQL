## 📌 Project Overview  
This project focuses on analyzing retail sales data using SQL to extract meaningful business insights. It demonstrates essential data analysis skills such as data cleaning, exploratory data analysis (EDA), and solving real-world business problems using structured queries.

The goal of this project is to showcase how SQL can be used to transform raw transactional data into actionable insights for better decision-making.

---

## 🎯 Objectives  
- Perform **data cleaning and validation**  
- Conduct **exploratory data analysis (EDA)**  
- Analyze customer behavior and sales trends  
- Solve business problems using SQL queries  
- Build a strong foundation in SQL for data analytics  

---

## 🗂️ Dataset Description  
The dataset contains retail transaction data with the following fields:

- `transactions_id` – Unique transaction identifier  
- `sale_date` – Date of transaction  
- `sale_time` – Time of transaction  
- `customer_id` – Unique customer ID  
- `gender` – Customer gender  
- `age` – Customer age  
- `category` – Product category  
- `quantity` – Number of items purchased  
- `price_per_unit` – Price per item  
- `cogs` – Cost of goods sold  
- `total_sale` – Total transaction value
